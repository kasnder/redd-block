# Windows store description

## Description
Block distracting websites and apps with ReDD Block, a focus tool based on our 10+ years of research on digital distraction.

Create beautiful blocklists, schedule focused time, and protect yourself from overriding blocks too easily.

🚫 Website Blocking: Block distracting websites across all browsers with system-level blocking that can't be bypassed 
📱 App Blocking: Automatically minimize distracting apps while a block is running 
🎨 Flexible Blocklists: Create multiple blocklists with custom emojis and colors for different contexts (e.g. Deep Work, Study Mode) 
📅 Visual Timeline: See your blocks on an interactive 24-hour timeline 
🔒 Override Protection: Make it hard to cancel blocks early with configurable difficulty challenges 
🔄 Multiple Concurrent Blocks: Run multiple blocklists at the same time 
💤 Background Operation: Blocks continue running even when the app is closed

ReDD Block is open-source and collects zero user data: https://github.com/ulyngs/redd-block
