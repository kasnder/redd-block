# Windows store description

## Description
----
NOTE: ReDD Block requires a helper daemon that runs in the background to enforce blocks - this is installed automatically when you first activate a block.
----

Block distracting websites and apps with ReDD Block, a free and open-source focus tool based on our 10+ years of research on digital distraction (reddfocus.org/research). Easily create blocklists, choose how long to block, and how difficult you want it to be to override.

🚫 Website Blocking: Instantly block websites across all browsers while a block is active
📱 App Blocking: Automatically minimize distracting apps while a block is active  
🎨 Flexible Blocklists: Create and customise multiple blocklists based on your needs
📅 Visual Timeline: See your active blocks on a 24-hour timeline 
🔒 Override Protection: Choose your difficulty setting for cancelling blocks early to hold yourself accountable
🔄 Multiple Concurrent Blocks: Run multiple blocklists at the same time 
💤 Background Operation: Blocks continue running even when the app is closed

ReDD Block is open-source and collects zero user data: https://github.com/ulyngs/redd-block
