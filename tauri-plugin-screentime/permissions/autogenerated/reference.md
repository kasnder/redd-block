## Default Permission

Default permissions for the screentime plugin

#### This default permission set includes the following:

- `allow-request-authorization`
- `allow-check-authorization`
- `allow-block-websites`
- `allow-unblock-websites`
- `allow-block-apps`
- `allow-unblock-apps`
- `allow-screentime-start-block`
- `allow-screentime-clear-block`
- `allow-schedule-block`
- `allow-unschedule-block`
- `allow-show-activity-picker`
